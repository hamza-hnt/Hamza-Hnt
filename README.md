## About Me

I am a software engineering student passionate about building clean, reliable, and scalable systems.

What drives me most is not only implementation, but the full engineering chain behind a solution: understanding needs, framing constraints, shaping architecture, making sound design decisions, and delivering something robust enough to operate in real conditions.

I enjoy working on projects that sit at the intersection of:

- **software architecture**
- **platform engineering**
- **distributed systems**
- **backend and APIs**
- **cloud and infrastructure**
- **automation / CI-CD / observability**

Beyond pure coding, I am especially motivated by the broader engineering perspective: translating product and business goals into technical systems, creating structure in complexity, and contributing through initiative, coordination, and leadership.

## Selected Work

Most of the projects on this GitHub account are private, but these are some of the projects that best represent the way I think and build.

### Featured Projects

- **CNP**  
  Platform engineering project where developers push code to GitHub and the platform automatically handles infrastructure provisioning, CI/CD pipeline creation, deployment workflows, messaging components, and monitoring when required.

- **Resilient Hybrid Cloud Architecture**  
  Self-service and redundant hybrid cloud architecture combining Azure and private cloud infrastructure, with secure networking, PostgreSQL failover, and high-availability design.

- **UBSI**  
  Designed and delivered a complete information system during a large-scale simulation involving around 50 participants, with major contributions to architecture and DevOps workstreams.

- **AURA**  
  Fully local AI assistant with JWT authentication, persistent memory, and PDF-aware Q&A, built with Spring Boot, Angular, PostgreSQL, and Ollama.

- **My-BitTorrent**  
  Modular BitTorrent client in C focused on protocol handling, peer communication, piece exchange, and clean architecture.

- **Tiger Compiler**  
  Modular compiler pipeline for the Tiger language, including lexical analysis, parsing, AST construction, desugaring, and intermediate representation generation.
