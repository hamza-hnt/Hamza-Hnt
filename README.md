## About Me

Software engineering student building **cloud platforms**, **backend systems**, and **AI-powered tools**. I enjoy working on **software architecture**, **agentic AI**, and **developer tooling**—from understanding a real need to designing and shipping a reliable system.

I'm especially interested in how **LLMs, tool use, and agent orchestration** can turn complex workflows into useful products, with clear boundaries and human control.

## Featured Work

### [CNP — Cloud Native Platform](https://cnp-overview.mindsept.fr/)

A repository-first developer platform that connects GitHub repositories to cloud-native delivery: stack analysis, CI/CD pull requests, container images, Kubernetes manifests, and deployment tracking. Developers stay in control through reviewed pull requests.

**Stack:** FastAPI, React, PostgreSQL, GitHub Actions, Docker, Kubernetes, Azure AKS.

### [ARCL — Resilient Hybrid Cloud Architecture](https://arcl.mindsept.fr/)

A hybrid architecture connecting Azure and private cloud infrastructure, with redundant application instances, PostgreSQL failover, self-service provisioning, and secure inter-site networking.

**Stack:** Azure, OpenTofu, Ansible, OpenStack, PostgreSQL, WireGuard.

### [FailSafe — AI Incident Response](https://failsafe.hamza-hnt.com/)

An AI-powered incident response system that connects production signals to source code, investigates incidents, and proposes fixes tested in isolation. Changes reach GitHub as reviewable pull requests, with human approval by default and recovery verified through health checks.
