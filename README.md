## Featured Work

Most of my strongest projects are private, but these are the ones that best represent how I think, design, and build.

### CNP — Cloud Native Platform

Repository-first platform engineering project that turns a GitHub repository into a production-oriented cloud-native delivery workflow.

CNP connects to GitHub through a **GitHub App**, imports repositories, performs deterministic stack analysis, generates human-approved **CI/CD Pull Requests**, publishes Docker images to **GHCR**, generates Kubernetes manifests, manages encrypted secrets, and tracks deployment status up to the public application URL.

The platform is designed around a control-plane mindset: developers keep ownership through Pull Requests, while the platform automates the repetitive infrastructure and delivery work behind the scenes.

**Current cloud path:** GitHub App → Stack analysis → CI PR → GHCR image → CD PR → Kubernetes manifests → Azure AKS deployment → Public URL tracking  
**Cloud direction:** Azure AKS, AWS EKS, GCP GKE, and private-cloud / OpenStack Kubernetes targets  
**Stack:** Python 3.12, FastAPI, React/Vite, PostgreSQL, Docker Compose, GitHub Actions, GHCR, Kubernetes, Azure AKS, AWS EKS, OpenStack/Private Cloud, JWT, Fernet

More in : https://cnp-overview.mindsept.fr/

---

### ARCL — Resilient Hybrid Cloud Architecture

Hybrid cloud architecture combining **Azure** and **private cloud infrastructure** with redundant application instances, PostgreSQL failover, self-service provisioning, infrastructure automation, and secure inter-site connectivity.

The project focuses on resilience, infrastructure-as-code, secure networking, and operational continuity across heterogeneous cloud environments.

**Stack:** Azure, OpenTofu, Ansible, MicroStack/OpenStack, PostgreSQL, WireGuard

More in : https://arcl.mindsept.fr/

### Tiger Compiler

Modular compiler pipeline for the Tiger language, including lexical analysis, parsing, AST construction, desugaring, and intermediate representation generation.

This project strengthened my understanding of language design, compiler architecture, C++ structure, and the engineering discipline needed to build complex systems step by step.

**Stack:** C++, Python, Autotools, Docker

### My BitTorrent

BitTorrent protocol implementation from scratch, focused on peer discovery, message exchange, piece management, and file chunk verification.

This project reflects my interest in systems programming, networking protocols, and clean low-level architecture.

**Stack:** C, Meson, SHA-1
